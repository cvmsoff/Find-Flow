Ajouter un appareil

Pour suivre un appareil, on y installe l'agent Find-Flow, puis on saisit le code ci-dessous. L'appareil apparaîtra alors dans la liste.

— — — — — —
  1. Installe l'application agent Find-Flow sur le téléphone ou le PC.
  2. Ouvre-la et saisis le code ci-dessus.
  3. Autorise la localisation. L'appareil se connecte tout seul.

Note : les agents (Android et Windows) ne sont pas encore disponibles — cet écran est prêt pour quand ils le seront.
